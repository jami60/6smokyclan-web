# 6smokyclan (6sc) — Official Beat Store & Frutiger Aero OS

Official Web Portal, Beat Store & Sound Vault for music collective **6smokyclan (6sc)** spearheaded by producer **6SCjami** ([@prod6scjami](https://www.youtube.com/@prod6scjami)).

Designed as a high-impact fusion of **[smokeybeats.com](https://www.smokeybeats.com/)** producer storefront features and the nostalgic aesthetics of **Windows XP Luna** & **Frutiger Aero (2006 Aqua Glass Edition)**.

## 🚀 Getting Started

### Local Setup
Ensure [Node.js](https://nodejs.org/) is installed:

```bash
# Clone the repository
git clone https://github.com/jami60/6smokyclan-web.git

# Enter the directory
cd 6smokyclan-web

# Run the local server
node server.js
```

Open your browser at:
👉 **`http://localhost:3000`**
